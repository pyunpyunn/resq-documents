## Folder guide

| Folder | Contents |
|---|---|
| `01_FINAL_DEFENSE` | Defense study guide, academic deliverables, and system diagrams. |
| `02_APIs` | API documentation grouped by shared, household mobile, rescuer mobile, web dashboard, and external partners. |
| `03_SYSTEM_DESIGN` | Requirements, use cases, and system architecture references. |
| `04_HOUSEHOLD_MOBILE` | Household app workflows and implementation notes. |
| `05_RESCUER_MOBILE` | Rescuer app, dispatch, GPS, offline navigation, and radio documentation. |
| `06_WEB_DASHBOARD` | Web dashboard behavior and feature notes. |
| `07_REPORTING_AND_INTEGRATIONS` | Situation reports, partner integrations, and report templates. |
| `08_DATABASE_AND_DATA` | SQL proposals, shared-database guidance, and geographic/hazard data. |
| `09_TESTING_AND_VERIFICATION` | Test plans, audits, implementation checks, and dated verification evidence. |
| `10_OPERATIONS_AND_DEPLOYMENT` | Backend/web, mobile build, and notification setup and run guides. |
| `11_DEVELOPMENT_PLANNING` | Development plans, checklists, prompts, step guides, and the SRS generator. |
| `12_RESEARCH_AND_REFERENCES` | Weather/hazard source material, technology references, and legal/resources lists. |

`02_APIs` has client-specific subfolders. Some API behavior is documented inside feature or integration guides rather than a standalone endpoint reference; the shared API reference and partner API contracts are placed in their corresponding folders.

`LEGACY_DOCUMENTATION_INDEX.md` is the index from the old layout and may contain links to paths that no longer apply. Use this README as the current navigation guide.
